# Smart-Uni · Pitch Interactivo v2

Pitch deck web de estilo startup / mobile-app, inspirado en la composición editorial de los pitch decks modernos de aplicaciones, pero diseñado específicamente para Smart-Uni.

## Abrir en VS Code

1. Descomprime el ZIP.
2. Abre la carpeta `SmartUni-Pitch-Interactivo-v2` en VS Code.
3. Abre `pitch.html` con Live Server (recomendado) o sirve la carpeta con cualquier servidor local.
4. Presenta en pantalla completa con el botón `⛶` o con la tecla `F`.

## Controles

- `→` / `←`: siguiente / anterior
- `Espacio`: pausar / reproducir
- `F`: pantalla completa
- `Home`: primera diapositiva
- `End`: última diapositiva
- Rueda del mouse: navegar

## Estructura

- `pitch.html` — presentación
- `styles.css` — estilo visual del pitch
- `app.js` — autoplay, transiciones y controles
- `prototype/` — copia del prototipo original de Smart-Uni

### Importante

Las pantallas que aparecen dentro de los dispositivos no son capturas inventadas: son el `index.html`, `styles.css` y `app.js` reales del prototipo original, cargados en iframes. La presentación solo crea el marco, la composición y el ritmo visual alrededor de esa interfaz.

No se incluye ni se copia el archivo de ningún template comercial de Envato; se utiliza únicamente una dirección visual general de pitch deck moderno.

## Nuevas escenas de identidad visual

Se añadieron cinco escenas nuevas al anuncio, sin modificar las pantallas existentes del prototipo:

- Identidad / logotipo
- Paleta de colores
- Tipografías y jerarquía
- Iconografía y acciones
- Sistema visual integrado

Estas escenas están construidas en HTML/CSS para conservar la estética de Smart-Uni y adaptarse a pantalla completa. Las referencias originales entregadas para el diseño también se conservan en `brand-reference/`.
