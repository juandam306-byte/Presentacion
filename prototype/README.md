# SmartUni

Prototipo web estático de SmartUni. No requiere dependencias ni compilación.

## Abrir en VSCodium

1. Descomprime `SmartUni-prototipo.zip`.
2. En VSCodium, usa **Archivo > Abrir carpeta** y selecciona la carpeta `SmartUni`.
3. Abre `index.html` en un navegador. También puedes usar una extensión de servidor local, como Live Server, si la tienes instalada.

Mantén `index.html`, `styles.css`, `app.js` y `smartuni-logo.svg` juntos en la misma carpeta.
